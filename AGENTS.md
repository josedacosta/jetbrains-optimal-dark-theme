## Project Overview

JetBrains Optimal Dark is a syntax highlighting theme for JetBrains IDEs. The theme is generated by comparing three source themes (Islands Dark, Darcula Contrast, Monokai) and selecting the best color for each parameter based on a rule-based hierarchy system.

## Language Rules

**All content in this repository must be written in American English.** This includes:
- Code and comments

**Exceptions (may remain in French):**

## Project Structure

- `theme/Optimal_Dark.icls` - The final output theme file (XML format)
- `builder/ideas/` - Source themes for comparison (Islands_Dark.icls, Darcula_Contrast.icls, Monokai.icls)
- `builder/prompt.md` - AI generation prompt with color selection methodology
- `README.md` - Complete documentation with color palette and justifications

## Theme Generation Workflow

This is a static asset project with no build system. The workflow is:

1. Read all three source themes in `builder/ideas/`
2. Copy Islands_Dark.icls as the base template
3. For each color parameter, compare across all three themes
4. Select the best option using the hierarchy rules in `builder/prompt.md`
5. Save to `theme/Optimal_Dark.icls`
6. Update `README.md` with color choices and justifications

## Design Hierarchy

When modifying colors, follow this importance hierarchy:

| Level | Elements | Treatment |
|-------|----------|-----------|
| CRITICAL | Keywords, errors, function declarations | Vivid, saturated colors |
| IMPORTANT | Numbers, parameters, constants, escapes | Distinctive colors |
| DATA | Strings, comments, documentation | Soft, desaturated colors |
| STRUCTURE | Operators, punctuation, braces | Neutral gray |
| METADATA | Annotations, decorators, HTML/XML tags | Tertiary colors |
| FEEDBACK | Warnings, TODO, deprecated code | Semantic colors |

## Key Color Sources

- **Monokai**: Vivid colors for critical elements (rose `#f92672`, green `#a6e22e`, cyan `#66d9ef`)
- **Islands Dark**: Soft colors for data/structure (green `#6aab73`, gray `#7a7e85`, background `#191a1c`)

## File Format

Theme files use JetBrains `.icls` format (XML):
- `<colors>` section: UI element colors
- `<attributes>` section: Syntax highlighting definitions

## Installation Testing

To test the theme:
1. In any JetBrains IDE: File → Settings → Editor → Color Scheme → Import Scheme
2. Select `theme/Optimal_Dark.icls`
